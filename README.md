# Serviços Eletrotécnicos

Landing page oficial do **Eletrotécnico GO**.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Railway

## Desenvolvimento local

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Produção

O projeto será publicado no Railway e conectado ao domínio:

`eletrotecnicogo.com.br`
